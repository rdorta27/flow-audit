700 of 5,000 orders have a problem that a person has to fix by hand

Flow Audit read 5,000 orders from Order manager, Activation system (3 sources) and looked for 3 patterns that make people redo work by hand. Measured: the orders and records counted here. Hours are an estimate and sit in the assumptions below.

Most orders affected

  1. Activation fails and nobody retries (R01) Measured 400 orders: An activation failed and nothing tried it again within the retry window, so a person has to find the order and push it through by hand.
  2. No end-to-end correlation id (R05) Measured 300 orders: Some records cannot be tied to their order by an id they carry, so a person has to work out which belong together.
  3. Duplicate service order (R04) Measured 20 orders: A second service order exists for the same order line. When activation failed, a retry created a new order instead of reusing the first.

Assumptions behind the hours

Projected Estimate with these assumptions: 299.2 h a month, each order counted once. It is an estimate, not a measurement and not money. Change a rate and it changes.
